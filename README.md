# Calculator GUI

A desktop calculator application built with **Java Swing**. This project was developed as part of my Advanced Java learning journey to practice GUI development, event handling, and application logic.

## Features

- **Basic Arithmetic Operations:** Addition, subtraction, multiplication, and division.
- **Percentage Calculation:** Convert a number into a percentage.
- **Decimal Support:** Perform calculations with decimal numbers.
- **Sign Toggle:** Switch between positive and negative numbers.
- **Backspace:** Remove the last entered digit.
- **All Clear (AC):** Reset the display and all calculation states.
- **Error Handling:** Handle division by zero and allow recovery from errors.
- **Formatted Results:** Display calculation results with clean decimal formatting.

## Technologies Used

- **Java** – Core programming language.
- **Java Swing** – Graphical user interface.
- **AWT** – Layout management, colors, fonts, and event handling.
- **Git & GitHub** – Version control and project hosting.

## Getting Started

### Prerequisites

- Java Development Kit (JDK)
- Visual Studio Code
- Java extensions for VS Code

### Run the Application

1. Clone the repository:
   git clone https://github.com/souadmd/Calculator-GUI.git

2. Open the project folder in VS Code.

3. Make sure the Java extensions are installed.

4. Open `src/Calculator.java`.

5. Run the application using the **Run Java** option.
